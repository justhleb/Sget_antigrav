# Шпаргалка: Переход с `schedule_mae` на `headway_mae`

Данная шпаргалка описывает процесс рефакторинга и ключевые изменения в логике имитационной модели (март 2026). Изменения были направлены на то, чтобы оптимизатор `NSGA-II` настраивал размер парка трамваев не для соблюдения абсолютного расписания, а для **минимизации отклонений от целевых интервалов движения**.

## Что изменилось?

- **Убрана метрика `schedule_mae` (ошибка расписания)** — модель больше не оценивается по тому, насколько точно трамвай приехал в запланированную минуту. Ранее в случае нехватки машин пропускались целые рейсы, и метрика могла некорректно считаться нулевой.
- **Внедрена метрика `headway_mae` (ошибка интервалов)** — модель оценивает разницу между *фактическим* временем между двумя соседними трамваями и *целевым* интервалом движения.

## Откуда берутся целевые интервалы?

Для 20-го маршрута был создан файл `side_data/time_data_20.json`.
При инициализации конфига (`RouteConfig.from_json()`), если в названии маршрута присутствует `"20"`, система парсит этот файл и сохраняет словарь почасовых целевых интервалов в переменную `config.target_intervals`.

Пример структуры в JSON:
```json
"target_intervals_minutes": {
    "from_kultury": { "14:00-15:00": 13 }
}
```

## Как производится расчет?

В момент окончания обслуживания остановки внутри `models/route.py` (`Route._arrive_at_stop()`):

1. **Определяется целевой интервал (`target_headway`)** по текущему часу симуляции и направлению:
   - `from_kultury` для направления `forward` (fwd).
   - `from_lenina` для направления `backward` (bwd).
2. **Определяется фактический интервал (`actual_headway`)**:
   - Берется время окончания посадки текущего трамвая.
   - Вычитается атрибут `stop.last_tram_departure_time`.
3. **Фиксируется ошибка (`headway_error`)**:
   - `headway_error = abs(actual_headway - target_headway)`.
4. Обновляется `stop.last_tram_departure_time = departure_time`.

## Затронутые модули:

- **`models/route.py`** — загрузка эталонных интервалов и расчет отклонений `headway_error`.
- **`models/stop.py`** — добавлено поле `last_tram_departure_time` (по умолчанию `None`).
- **`models/tram.py`** — переименование аргументов с `delay` на `headway_error`. **Важное исправление:** удалена блокировка `if self.lightweight_mode: return` в логировании отклонений, чтобы `optimizer.py` получал фактические ошибки интервалов при быстром прогоне без графиков.
- **`logger.py`** — везде колонки `delay_min` переименованы в `headway_error_min`. В `trams_summary.csv` теперь записываются `avg_headway_error_min` и `max_headway_error_min`.
- **`simulation/multi_route.py`** — `get_objectives` и `get_full_stats` пересчитывают `headway_mae` на основе собранных массивов отклонений.
- **`optimizer.py` / `debug_sim.py`** — скрипты запуска были адаптированы под новые ключи метрик.

## Где смотреть логи?

CSV датафрейм `outputs/run_.../logs/{route}/schedule_deviations.csv` теперь содержит колонку **`headway_error_min`**. Идеальное поведение оптимизатора — сделать так, чтобы среднее значение в этой колонке было минимальным, несмотря на неравномерность дорожного движения и пассажиропотока.
